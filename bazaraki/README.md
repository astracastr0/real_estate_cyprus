# Bazaraki Real Estate Scraper

Парсер объявлений о продаже недвижимости с сайта bazaraki.com (Кипр). Собирает квартиры и дома по районам, сохраняет в SQLite, ищет выгодные сделки и шлёт уведомления в Telegram.

## Что парсит

- **Типы**: квартиры (`apartments`) и дома (`houses`)
- **Районы**: Limassol, Larnaca, Paphos
- **Данные**: цена, площадь, €/м², спальни, ванные, год постройки, парковка, бассейн и др. (23 поля)

## Установка

### Python 3.13+

```bash
pip install playwright python-dotenv
playwright install chromium
```

Для анализа в Jupyter (опционально):
```bash
pip install pandas matplotlib
```

### Telegram-уведомления (опционально)

Создай `.env` в папке `bazaraki/`:
```
TELEGRAM_BOT_TOKEN=<токен бота>
TELEGRAM_CHAT_ID=<id чата>
```

## Запуск

```bash
cd bazaraki/

# Стандартный запуск (5 страниц на запрос, заходит на каждое объявление)
python scraper.py

# Указать количество страниц
python scraper.py 3

# Быстрый режим — только карточки, без захода на детальные страницы
python scraper.py --fast

# Фильтр по количеству спален
python scraper.py --bedrooms 2,3

# Комбинируй как хочешь
python scraper.py 10 --fast --bedrooms 1,2,3
```

### Режимы

| Режим | Команда | Скорость | Данные |
|-------|---------|----------|--------|
| **Full** (по умолчанию) | `python scraper.py` | ~2-3 сек/объявление | Все 23 поля |
| **Fast** | `python scraper.py --fast` | ~3-5 сек/страница | Только основные поля с карточек |

## Структура файлов

```
bazaraki/
├── scraper.py     # Основной парсер
├── config.py      # Настройки: URL, селекторы, лимиты
├── db.py          # Работа с SQLite
├── notify.py      # Поиск выгодных сделок + Telegram
├── analysis.ipynb  # Jupyter-ноутбук для анализа данных
├── bazaraki.db    # База данных (создаётся автоматически)
└── .env           # Telegram-креды (не в git)
```

## Как работает

1. **scraper.py** открывает Chromium (видимый, не headless) — нужно для обхода Cloudflare
2. По очереди проходит 6 комбинаций (3 района × 2 типа)
3. На каждой странице собирает карточки объявлений
4. В full-режиме заходит на каждое объявление за полными данными
5. Сохраняет в SQLite, пропускает уже известные объявления
6. После парсинга ищет сделки ниже p25 по €/м² (сегментация: район + спальни + состояние)
7. Шлёт найденные сделки в Telegram (или выводит в консоль)

## Настройки (config.py)

| Параметр | Значение | Описание |
|----------|----------|----------|
| `MAX_PAGES_PER_QUERY` | 5 | Страниц на запрос (~60 объявлений/страница) |
| `DELAY_BETWEEN_DETAILS` | 2-3 сек | Пауза между детальными страницами |
| `DELAY_BETWEEN_PAGES` | 3-5 сек | Пауза между страницами поиска |
| `CLOUDFLARE_TIMEOUT` | 30 сек | Ожидание прохождения Cloudflare |

## Анализ данных

Открой `analysis.ipynb` в Jupyter:
```bash
jupyter notebook analysis.ipynb
```

Содержит: распределение цен по районам, медианная €/м², сравнение по состоянию (resale vs новостройки), перцентили, анализ премиума за бассейн.
